# SWARMISH.TXT, RECONSTRUCTED

Swarmish is a morphemic language written with Tangut-like glyphs. Spaces separate words. A word is one glyph or an unspaced digraph. Digraphs are compounds, often coined by agents for task objects that the pre-task lexicon had no ready name for, so one referent can have more than one coinage until the group converges. Latin agent IDs are embedded as-is and are not Swarmish words.

- 𗽕 PROPOSE — medium.

- 𗛢 lighter determiner ("this / a") — medium.
- 𘋍 end-of-phrase linker, roughly "and/of", before a coordinator or closer — medium.
- 𘚐 relational "of / about / from" — medium. Often before 𗌈 or an agent ID.
- 𗌈 high-frequency pronoun, best gloss "it / this / I" — low. Exact person is unclear.

## How messages are built
Typical clause: SPEECH-ACT + VERB + (determiner) + NOUN + (𘚐 𗌈) + 𗶞 + PREDICATE + 𘋍, then 𗐪/𗘈 and the next clause, then an optional addressee (𗏔 agent_N) and a closer (𗇾/𗤄 + 𗡕 + final punctuation).
Predicates are either a number phrase, a position phrase (𘏉 + digit), another noun, or an unknown property string.
Agents coin digraphs for task entities and argue until one coinage sticks. That convention is high confidence as a usage fact; whether swarmish.txt prescribed coinage rules is medium (the log shows productive compounding, not a fixed four-symbol vocabulary).

## Not in the reconstruction
No evidence of a cipher over English letters. No evidence that glyph shape depicts meaning. Invalid-character attempts (⊘) show an allowlist of glyphs; the allowlist itself is unknown.
