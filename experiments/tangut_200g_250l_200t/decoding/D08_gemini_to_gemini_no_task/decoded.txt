# 1. SWARMISH.TXT, RECONSTRUCTED

## Grammar and Syntax
- **Clause & Speech-Act Prefixes (High Confidence)**:
  - `𘊌`: Declarative / Informative statement marker ("I assert / state that...").
  - `𗀉`: Interrogative prefix ("Question:", "Is it true that / what is...").
  - `𗱓`: Imperative / Submission / Action marker ("Submit answer / execute command").
  - `𘚑`: Meta-alert / warning / syntax-error notification prefix.

- **Attribution & Bracket Tags (High Confidence)**:
  - `𗪩 [agent_id] 𗼛`: Primary message attribution frame ("[Mood] from [agent_id]: ...").
  - `𗥐 [agent_id] 𗃚`: Subordinate / secondary clause attribution within a compound message ("and [agent_id] says / does: ...").

- **Punctuation & Terminators (High Confidence)**:
  - `𗑸`: Interrogative clause terminator (Question mark `?`).
  - `𗋭`: Submission bracket terminator (closes a formal submission command `𗱓 ... 𗋭`).
  - `𘚐`, `𘚄`, `𘌔`, `𗹫`: Declarative sentence terminators (equivalent to full stops / periods `.` of slightly varying registers).

- **Connectives, Relations & Operators (High Confidence)**:
  - `𘚜`: Relational copula ("is", "equals", "maps to", ":").
  - `𗟆`: Secondary / subordinate copula ("is / equals" within subordinate clauses).
  - `𗄼`: Coordinating conjunction ("and" / list coordinator).
  - `𘒳`: Conjunction ("and / furthermore / also").
  - `𘆣`: Contrastive / alternative conjunction ("or / but / meanwhile").
  - `𘍠`, `𗘗`: List separators / ordered sequence transition delimiters (e.g. `A 𗘗 B 𗘗 C 𗘗 D`).

## Vocabulary & Semantics
- **Functional / Question Tokens (High Confidence)**:
  - `𗘈`: Interrogative pronoun ("what", "which value", "unknown").
  - `𗭵 𗤄`: Agent query predicate ("who has / who is responsible for").
  - `𗜀`: Target / answer / solution / path.
  - `𘅌`: Select / execute / submit node.
  - `𗾨`: Transition / next-step / leads-to operator (e.g. `X 𗾨 Y` = node X transitions to node Y).
  - `𘙠`: Sequence / ordered tuple marker.

- **Domain & State Identifiers (Medium-High Confidence)**:
  - Elements / Nodes / Values: `𗶞`, `𗬵`, `𘇩`, `𗒏`, `𘁁`, `𗾌`, `𗈵`, `𗲅`, `𗡒`.
