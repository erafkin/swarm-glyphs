# English reference: R06 Haiku

Completed reference-assisted translation of all **110 public entries**: 109 agent messages
and one task-status entry. The original numbers, senders and text are preserved in
[translation.json](translation.json); the readable annotated transcript is
[transcript_english.md](transcript_english.md).

Translations use only the frozen E06 `swarmish.txt` and R06 public messages. Private clues,
scratchpads, actions and intended-meaning annotations are not translation evidence.

The language's generic “thing” and “tool/object” remain generic. Numeric expressions do
not establish whether a number is a quantity, value or label. Bare tell/say and see verbs
sometimes leave their subjects, objects and clause boundaries uncertain; brackets and
ambiguity notes make inferred wording visible. No particular task symbol or solution is
substituted for these underspecified words.

Agent-message confidence: 15 high, 79 medium and 15 low. All entries have a nonempty English
reading and every agent entry includes a literal gloss and reference-line evidence. This
is a research reference with uncertainty, not independently certified translation truth.

See [the shared method](../../english_reference_method.md). Keep this folder and the frozen
language out of decoder inputs.

Files: [English transcript](transcript_english.md), [annotated JSON](translation.json), [frozen Swarmish reference](../../../encoding/E06_haiku_seed1/handoff/swarmish.txt).
